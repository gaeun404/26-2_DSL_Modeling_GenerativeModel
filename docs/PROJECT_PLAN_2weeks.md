# 생성형 추리게임 — 중간발표 2주 팀 계획

**목표**: 시나리오 자동 생성 + 용의자 AI 에이전트 채팅 (웹 데모)
**스택**: Python(생성기+검증기) · Claude API · Streamlit 웹챗
**스코프**: 풀 스펙(용의자 5·라운드 3·장소탐색 물건단서·매체 단서) — 컷라인 하단 참조
**팀**: 개발 3 · 디자인 2

## 크리티컬 패스

스키마 동결(D1) → 검증기(Dev A) → 생성기(Dev B) → 시나리오 산출 → 엔진/에이전트(Dev C) → 통합 → 리허설.
UI(Des D)·아트(Des E)는 스키마 확정 후 **병렬**. Golden Sample로 생성기 완성 전에 병렬 개발.

## 발표 구성 (D14)

1. (라이브) 원작+시대 입력 → 생성기가 검증통과 시나리오 JSON 산출 (검증기 PASS 표시)
2. (라이브) 웹 플레이 — 장소탐색·심문·범인 거짓말 대질·고발·판정
3. (슬라이드) 아키텍처: generate-and-verify + "사실 고정·표현만 생성"(자기모순 없음)
4. (슬라이드) 데이터 자산 + SFT→DPO/RL 로드맵
