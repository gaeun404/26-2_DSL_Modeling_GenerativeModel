## 단서가 손에 들어오는 길은 **넷**뿐입니다

| 길 | 언제 | 예산 | 화면 |
|---|---|---|---|
| **① 자동 지급** | 라운드가 시작될 때 저절로 | 0 | 토스트 + 수첩에 추가 |
| **② 장소 조사** | 지도 → 장소 → 선택지를 눌러야 | **1** | 장소 조사 화면 |
| **③ 심문 실토** | 정곡을 찔러 ADMIT을 끌어내면 소지품이 딸려 옴 | **1** | 심문 화면 |
| **④ 단서 조합** | 수첩에서 단서 두 장을 겹치면 | 0 | 사건수첩 |

`channel` 값이 곧 길입니다.

```
channel = "crime_scene"  → ① 자동 (현장 브리핑, 1라운드에 전부)
channel = "spine"        → ① 자동 (증언이 저절로 들어옴)
channel = "location"     ┐
channel = "record"       ├→ ② 장소를 뒤져야 나옴
channel = "physical"     ┘
belongings[]             → ③ 심문 ADMIT
clue_combos.combos[]     → ④ 수첩 조합
```

> **엔진 코드로는** — `next_round()`가 ①만 `held_clues`에 넣습니다.
> ②는 `search(place_id, i)`, ③은 `interrogate()`의 `yielded_belonging`, ④는 `combine()`입니다.

## ① 자동 지급 — 화면에 어떻게 뜨나

라운드가 시작될 때 그 라운드의 `spine` 단서가 **저절로** 들어옵니다. 플레이어는 아무것도 안 눌러도 됩니다.

```
🔔 토스트          "2라운드가 시작됩니다."      ← ui.toasts[round_start]
▶ 라운드 배너      "2라운드 — 관계를 판다"      ← ui.hud.copy.round_banner
▶ 나레이션         "2라운드. 밤이 깊어 간다…"    ← ui.story_narration.round_start["2"]
🔎 토스트          "새로운 단서가 제시되었습니다"  ← ui.toasts[clue_new]
   └ 수첩 단서 탭에 카드가 추가됨
```

**1라운드 현장 브리핑(`crime_scene`)은 예외** — 라운드 시작이 아니라 **현장 화면(08)**에서
사이드바에 한꺼번에 보여줍니다. 게임 시작할 때 이미 손에 있습니다.

### `spine` 단서는 전달 방식이 다릅니다

대부분 `presentation.mode = "spoken"`입니다. **텍스트 카드가 아니라 사람이 나와서 말합니다.**

```jsonc
"presentation": {
  "mode": "spoken", "speaker": "서민재", "speaker_kind": "cast",
  "script": "명패는 제가 ㄱㄴㄷ 순으로 붙였어요. 그런데 회의 때 보니…",
  "stage": "화자가 화면에 등장해 초상·음성과 함께 직접 말한다. 텍스트 카드로 대체하지 않는다."
}
```

`speaker_kind`가 `cast`면 그 용의자 초상을, `npc`면 `render.frame`대로 새로 그립니다.

## ② 장소 조사 — 눌러야 나옵니다

**지도(12) → 장소(13) → 선택지 4개 중 하나를 누름 → 예산 1 소모**

한 장소·한 라운드에 **선택지가 4개**, 그중 단서가 나오는 건 보통 1개입니다. 나머지는 헛수고입니다.

```jsonc
// ui.place_screens[].rounds["1"].actions[0]
{ "label": "CCTV를 조사한다",
  "result_lines": [
    "CCTV를 조사했다.",
    "CCTV는 특별할 것 없어 보인다.",
    "그런데 자판기 CCTV — 휴식 시간에 지원·은민·승원이 차례로 찍혔다.",   ← 이 줄이 강조됨
    "새로운 단서를 발견했다." ],
  "highlight_last": true,
  "finds": "K11",                 ← null이면 헛수고
  "button": "단서 보기",           ← 헛수고면 "계속 조사"
  "sfx": ["event_cues.search_hit", "event_cues.clue_found", "ui.audio.sfx.counter_up"] }
```

**헛수고일 때**는 `finds: null`, `button: "계속 조사"`, `sfx: ["event_cues.search_miss"]`,
`result_lines` 마지막 줄이 "이렇다 할 것이 없다" 류입니다. **예산은 똑같이 1 소모됩니다.**

화면 하단 카운터: `"발견한 단서 {found} / ?"` — 총 개수는 안 알려줍니다.

## ③ 심문 실토 — 소지품이 딸려 옵니다

정곡 트리거를 찔러 **ADMIT**을 끌어내면, 그 비밀에 딸린 소지품이 손에 들어옵니다.

```
💬 심문 → 태도 ADMIT
🔓 토스트  "비밀이 드러났습니다."   ← ui.toasts[secret_open]
   └ 소지품 획득: 학회 사물함에서 나온 것
```

91편 소지품 5개 — `B1` 서민재 / `B2` 노하람 / `B3` 임세준 / `B4` 유가람 / `B5` 차연우.
**각 인물의 비밀 하나당 하나**입니다. 심문을 안 하면 이 5개는 영영 못 얻습니다.

> 소지품은 `points_to`가 없습니다 — **범인을 가리키지 않습니다.**
> 채점(`비밀 1개당 1점`)에만 쓰이고, 범인 특정은 ②의 장소 단서가 담당합니다.
> 그래서 탐색만 하면 범인은 맞히지만 점수가 낮고, 심문만 하면 점수는 높은데 범인을 못 짚습니다.

## ④ 단서 조합 — 수첩에서 겹칩니다

**사건수첩(15) → 단서 탭 → [겹쳐 본다] → 다른 단서 선택**

```jsonc
{ "id":"CB1", "needs":["K1","K2"], "title":"니코틴 원액 탄 아이스 아메리카노는 어떻게 쓰였나",
  "yields":"…어떻게 쓰였는지가 맞춰진다 — 시간차 독살 — 암전 15분의 얼개가 드러난다.",
  "unlocks":"트릭 항목이 수첩에 정리된다", "points":1, "round_min":1 }
```

- **둘 다 이미 얻은 뒤**에만 겹칠 수 있습니다
- `round_min` 이전에는 "아직 이 둘을 잇기엔 아는 것이 부족하다"
- 같은 조합을 다시 하면 `already_done: true`, **점수는 0** (중복 적립 방지)
- **예산을 쓰지 않습니다** — 수첩에서 생각하는 일이지 행동이 아닙니다

## 이벤트는 어떻게 등장하나

**전 편 2라운드**입니다(`events[].round`). 라운드 시작 직후에 터집니다.

```
🔔 토스트     "판이 뒤집힙니다."              ← ui.toasts[event] · event_cues.event_sting
▶ 연출        화면이 한 번 흔들림             ← story_narration.event["2"].shot
▶ 나레이션    "그런데 — 임세준이 감추던 것이
              남의 입에서 먼저 나온다.
              판이 뒤집힌다. 지금까지 세운
              셈을 다시 세워야 한다."         ← 건너뛸 수 없음(skippable: false)
▶ 실제 효과   C3의 비밀 단서가 즉시 공개되고,
              그 인물의 압박이 한 단계 오른다  ← events[].effect
▶ 해금        여기서부터 [대질] 화면이 열림    ← cross_examination.unlock_round
```

**이벤트 전에 대질을 누르면** 화면이 잠겨 있습니다. 토큰도 예산도 깎이지 않습니다.

```jsonc
"cross_examination": {
  "unlock_round": 2, "unlock_by": "event",
  "locked_copy": {
    "title": "아직 맞대 놓을 수 없다",
    "body": "사람을 맞대 놓으려면 판이 한 번 뒤집혀야 한다. 아직 그럴 만한 일이 일어나지 않았다.",
    "hint": "{r}라운드에 무슨 일이 생긴 뒤에 다시 오라." }
}
```

## 프론트가 지켜야 할 것

1. `channel`로 길을 가릅니다 — `spine`/`crime_scene`은 **주는 것**, 나머지는 **찾는 것**
2. `reveal_round` 이전에는 **존재 자체를 노출하지 않습니다** (수첩에도 안 보임)
3. `finds: null` 선택지도 **예산을 씁니다** — 헛수고가 비용이어야 선택에 무게가 생깁니다
4. `presentation.mode = "spoken"`은 **인물이 나와서 말합니다** — 텍스트 카드로 대체 금지
5. 조합·감식·대질은 **예산을 쓰지 않습니다**
6. 대질은 이벤트 전까지 **잠겨 있고**, 잠긴 상태에서 누르면 토큰·예산 둘 다 보존
