## 전체 활용 흐름

```
[C]배경(설화/조선) + [B]코난 트릭·동기 사전 + [A]MuSR 논리구조·Jubensha 다인구조
                          │  (시드 · 패턴 · 본보기)
                          ▼
                  ★ 생성기(harness) ★   3명 이상 용의자 시나리오 생성
                          │             (각자 동기+비밀, 범인만 거짓말)
                          ▼
                  ★ 검증기(rule-based) ★  타임라인 모순 / 유일해 / 균등의심 / ~50% 난이도
                          │  (통과분만 채택)
                          ▼
        ┌──────────── 다량 학습 데이터 ────────────┐
        │   SFT 콜드스타트  →  DPO (RLAIF)           │
        └───────────────────────────────────────────┘
                          │
   평가: [A]WhoDunIt·DetectiveQA·TrueDetective   |   인물 에이전트 말투: [D]
```

## 핵심 3원칙

1. **완성형 다용의자 시나리오는 공개 데이터에 없다** → 받은 데이터는 전부 생성용 시드·패턴·본보기·평가. 데이터 자체가 최종 학습정답이 아님(코난·MuSR 포함).
2. **실제 케이스(A)는 총 ~1.5k** → SFT 워밍업 + 평가용. 본 학습의 "다량"은 검증 통과한 합성분이 채운다.
3. **저작권물(B, ⚠️)은 패턴 추출·재작성 전용** → 원문을 산출물/학습 타깃에 넣지 않는다. provenance(source_url·license) 유지.
