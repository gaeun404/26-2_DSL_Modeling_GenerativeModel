# API 명세 — 여섯 잔의 회의

뽑은 날 2026-08-28 · 서버 `server.py` · 자동 문서 `/docs` · 배선 확인 `/demo`


## 먼저 알아야 할 것

* **화면에 뜨는 것만 내려온다.** `is_culprit`·`points_to`·안 열린 비밀·정답은 어떤 응답에도 없다.
  지목(`/accuse`) 뒤에야 진상·재연·엔딩이 열린다. 프론트가 다 받아 놓고 숨기는 구조가 아니다.
* **거의 모든 응답에 `state`가 들어 있다.** 행동 뒤에 상태를 따로 부를 필요가 없다.
* **행동 예산**은 라운드당 8. 탐색(무언가 나온 방)과 심문이 같은 주머니를 쓰고,
  대질은 예산 밖(한 판 1회), 첫 대면·수첩·조합은 0이다.
* 오류는 HTTP 400/404에 `{"detail": "사람이 읽을 한 줄"}`. 그대로 띄워도 되는 문장으로 적었다.
* 세션은 메모리에 두 시간. 시연용이라 그렇게 뒀다 — 여러 대에서 이어 하려면 그때 DB를 붙인다.

## 화면 ↔ 엔드포인트

| 화면 | 무엇 | 부르는 것 | 메모 |
|---|---|---|---|
| `S-05~S-10` | 사건 공개 · 오프닝 · 현장 · 피해자 · 용의자 | `POST /session` | 판을 열면서 도입 구간에 필요한 것을 **한 번에** 받는다. 화면을 넘길 때마다 부르지 않는다. |
| `S-11` | 라운드 화면(상시 프레임) | `GET /session/{sid}/state` | 라운드·남은 행동·대질 잠금·인물 카드·수첩이 다 들어 있다. 조각을 여러 번 부르면 어긋난다. |
| `S-13` | 지도 | `GET /session/{sid}/map` | `searched`가 참이면 이번 라운드엔 이미 본 방이다. |
| `S-14` | 장소 조사 | `POST /session/{sid}/search` | **무언가 나온 방만 1턴.** `empty:true`면 턴이 줄지 않는다 — 「여긴 오늘 밤 달라진 게 없다」. |
| `P-06` | 첫 대면 알리바이 | `POST /session/{sid}/meet/{cast_id}` | 예산 0. 두 번째부터 `already:true`. 심문 화면에 들어갈 때 한 번 부르면 된다. |
| `S-15` | 심문 | `POST /session/{sid}/ask` | `clue_id`를 함께 보내면 그 단서 문장이 질문 앞에 통째로 붙는다(= 증거를 들이댄 것). `stance`로 초상·연출을 고른다. `line`이 null이면 서버에 키가 없다는 뜻이다. |
| `S-16` | 대질 | `POST /session/{sid}/confront` | 한 판 1회, 예산 밖. 잠겨 있으면 400. 짝에 따라 나오는 내용이 다르다. |
| `S-12·S-20` | 라운드 시작·종료 | `POST /session/{sid}/next_round` | 자동 공개 단서와 이벤트가 함께 온다. `event_result`가 실제로 일어난 일이다(비밀·단서·압박). |
| `S-18` | 사건수첩 | `GET /session/{sid}/notebook` | 단서만. 인물은 `state.cast`에 있다. `roles`가 있으면 그 직책이 누구인지 곁들여 준다. |
| `S-21~S-24` | 지목 · 진상 · 재연 · 엔딩 | `POST /session/{sid}/accuse` | **여기서 처음** 진상이 열린다. 그 전에는 어떤 응답에도 정답이 실리지 않는다. |

## stance — 심문 응답의 다섯 가지

| 값 | 뜻 | 화면 |
|---|---|---|
| `ANSWER` | 묻는 사실을 그대로 답한다 | 평정 |
| `DEFLECT` | 부인하거나 말을 돌린다 | 평정 |
| `FLINCH` | **정곡을 맞혔다.** 그러나 증거가 모자라 인정하지 않는다 | 흔들림 · 압박 상승 |
| `ADMIT` | 비밀 하나를 인정한다 | 무너짐 · `secrets_opened`에 문장이 온다 |
| `BREAK` | 범인이 무너진다(결정타 + 임계 압박) | 결정타 연출 |

**비밀이 열리는 길은 둘이다.** ① 그 비밀을 여는 단서를 `clue_id`로 내밀면 한 번에.
② 증거 없이 같은 자리를 세 번(물증을 들고 있으면 두 번) 물으면.

## 배포

```bash
pip install -r requirements.txt
python3 server.py --host 0.0.0.0 --port 8000
```

* `MM_API_KEY`를 서버 환경변수로 주면 용의자 대사를 서버가 만든다. **키는 브라우저로 나가지 않는다.**
* 키가 없으면 `line: null`로 내려온다 — 프론트는 그 자리를 비워 두면 된다(판단은 그대로 온다).
* CORS는 전부 열어 뒀다. 외부에 세울 거면 `allow_origins`를 프론트 도메인으로 좁혀야 한다.
