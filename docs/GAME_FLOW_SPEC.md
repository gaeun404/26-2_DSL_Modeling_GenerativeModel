# 게임 진행 명세 (디자인팀 전달용)

시나리오팀 → 디자인팀 계약 문서. "게임이 정확히 어떻게 굴러가는가"를 화면 단위로 고정.

## 0. 게임 파라미터

| 항목 | 값 |
|---|---|
| 용의자 | 5명 |
| 라운드 | 3 |
| 심문 턴 | 라운드당 8턴(질문 8개, 용의자에게 자유 배분) |
| 장소 탐색 | 라운드당 장소별 1회(그 라운드 reveal_round 물건 1개) |
| 고발 시점 | 매 라운드 종료 후 (선택) / 라운드 3 종료 시 강제 |
| 목숨 | 5 (오답 −1, 0이면 패배) |
| 정답 | 범인(5지) + 동기(5지) + 흉기(5지) 전부 일치 |
| 거짓말 | 범인만. 무고자는 진실(비밀은 회피 가능) — 심문(S5)에서만 |

## 1. 상태 전이도

```
S1 타이틀 → S2 인트로 → S3 신원공개+규칙
   → ┌──────── S4 조사 허브 (라운드 R) ────────┐
     │  ├─[용의자]→ S5 심문챗 (−1턴)             │
     │  ├─[장소]→ S6 장소탐색 (물건단서)          │
     │  └─[증거노트] 열람                        │
     │       (턴 소진 or [라운드 종료] 클릭)       │
     └──────────────┬───────────────────────┘
                    ▼
        S7 라운드 단서 공개(스파인 1개·매체)
                    ▼
     [고발한다]──▶ S8 고발 ──▶ S9 판정 ──(승/패 or 계속)
     [더 조사]──▶ R<3: S4(R+1) / R=3: S8 강제
```

## 2. 화면별 명세

### S1 타이틀
- 요소: 게임 타이틀, [시작] 버튼, 배경 일러스트/BGM
- 인터랙션: [시작] → S2
- 데이터: 없음(고정)

### S2 인트로 시네마틱 (3비트 순차)
- 비트①원작 나레이션 → 비트②분위기 반전 → 비트③사망 선언
- 요소: 전면 나레이션 텍스트(+배경 영상/이미지), [계속] 또는 자동진행
- 데이터: `meta.origin`, `intro.original_summary`, `intro.twist`, `victim.name`, `death.place/time_slot` (흉기·수법은 **비공개**)
- 인터랙션: [계속] → S3

### S3 신원 공개 + 규칙
- 요소: 피해자 카드 1 + 용의자 카드 5(초상·이름·공개직함), 규칙 배너("범인만 거짓을 말한다")
- 데이터: `victim`, `cast[].name/public` (동기·비밀·범인여부는 **숨김**)
- 인터랙션: [수사 시작] → S4 (라운드 1)

### S4 조사 허브 ★메인 화면★
- 상단 HUD: 라운드 `R/3`, 남은 심문 턴 `n/8`, 목숨 ♥×(1~5)
- 좌측: **장소맵** — 장소 아이콘들(탐색 완료 표시)
- 우측: **용의자 목록** 5명(초상)
- 하단: [증거노트] 열기, [라운드 종료] 버튼, (조건부) [고발] 버튼
- 데이터: `places[]`, `cast[]`, 진행상태(턴·라운드·목숨·수집단서)
- 인터랙션:
  - 용의자 클릭 → S5
  - 장소 클릭(미탐색) → S6
  - [증거노트] → 수집한 단서 목록 모달
  - 턴 0 또는 [라운드 종료] → S7

### S5 심문 챗
- 요소: 용의자 초상+이름, 대화 로그(말풍선), 입력창/추천질문, 남은 턴
- 인터랙션: 질문 전송 → 답변(−1턴). 턴 0이면 입력 잠금 → S4 복귀
- 데이터(에이전트 구동): `cast[해당].{public, timeline, alibi, secret, is_culprit, lies}`
  - 무고자: 사실 기반 진실, 비밀은 회피 가능 / 범인: `lies`에 박힌 거짓만 반복
- 전이: [나가기] → S4

### S6 장소 탐색
- 요소: 장소 일러스트, 발견 연출(물건 클로즈업), 물건 설명(surface만)
- 데이터: `places[해당].objects[ reveal_round==R ]` 의 `surface`(+`medium`이 있으면 그 형태)
  - `implies`(숨은 의미)는 **화면에 안 뜸** — 플레이어가 추론
- 인터랙션: 발견 → 증거노트 자동수집 → S4 복귀
- 규칙: 라운드당 장소별 1회

### S7 라운드 종료 단서 공개 (스파인)
- 요소: 매체 형태 카드(검안서/신문/증언)로 스파인 단서 1개 "쾅" 공개, 감정비트=충격
- 데이터: `clue_graph[ channel=="spine" && reveal_round==R ]` 의 `medium`+`surface`
- 인터랙션: [고발한다] → S8 / [더 조사한다] → S4(R+1) (R=3이면 자동 S8)

### S8 고발
- 요소: 3개 셀렉터 — 범인(용의자 5), 동기(`motive_choices` 5), 흉기(`weapon_choices` 5), [고발 확정]
- 데이터: `cast[]`, `motive_choices`, `weapon_choices`
- 인터랙션: 3개 선택 → S9

### S9 판정
- 정답(3요소 일치): 승리 엔딩 — `solution.reason` 나레이션(왜 그 사람인지 논리)
- 오답: 목숨 −1 → 남으면 S4 복귀(재수사), 0이면 패배 엔딩
- 데이터: `solution.{culprit, motive_label, weapon, reason}`, 진행 목숨

## 3. 라운드 루프 & 행동 경제

- 라운드 시작 → S4에서 **심문 8턴 + 장소별 1탐색**을 자유 소비
- 심문 1질문 = −1턴 / 탐색은 턴 무관, 장소별 1회 제한
- 턴 소진 또는 [라운드 종료] → S7 스파인 단서 → 고발 분기
- 3라운드 반복. 결정적 스파인 단서는 라운드 3에 배치(반전)

## 4. 데이터 → 화면 매핑 (시나리오팀↔디자인팀 정렬)

| 시나리오 JSON 필드 | 뜨는 화면 | 표시 형태 |
|---|---|---|
| meta.origin, intro.* | S2 | 나레이션 |
| victim, death(장소/시간만) | S2,S3 | 카드/나레이션 |
| cast[].name/public | S3,S4 | 용의자 카드 |
| cast[].timeline/alibi/secret/lies | S5 | 에이전트 답변(숨은 데이터) |
| places[].objects[].surface/medium | S6 | 물건 단서(관찰만) |
| clue_graph(spine).surface/medium | S7 | 매체 단서 카드 |
| motive_choices, weapon_choices | S8 | 셀렉터 보기 |
| solution.* | S9 | 판정 나레이션 |
| implies / points_to / exculpates | (없음) | **검증기 전용, 화면에 안 뜸** |

★ 원칙: 화면엔 **관찰(surface)**만, **결론(implies·정답)**은 숨김. 플레이어가 추론.
