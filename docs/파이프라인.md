# 시나리오·게임 스키마 생성기 — 완성본 (시나리오팀)

원작 한 줄 입력 → **상세 원본 소설(바이블)** → **게임 스키마 JSON** → **검증 + 난이도 게이트 통과분만** 산출.
플레이·에이전트·채점까지 한 키트로 완결.

## 전체 파이프라인

```
원작(예: "흥부전","조선")
      │
[condition_sampler]  코난 트릭 · SHR 현실동기 · 원작 원문을 프롬프트 조건으로 주입
      ▼
[generate · Stage1]  gen_bible()   → out/bible.md  (세계·인물 감정·관계·과거·그날 전부, 진실 포함)
      ▼
[generate · Stage2]  extract_schema() → scenario.json
                     (타임라인·단서·MMO·solution + cast[].bio + cast[].profile)
      ▼
[verify]      solvable? (R1 타임라인·R2 유일해·R3 균등의심·R4 범인만거짓·R5 결정타·MMO·흉기·보기)
[difficulty_gate]  안 뻔한가? (마지막 라운드 붕괴 · 추론 필요 · 2/3 갖춘 가짜 유력자)
      │  둘 다 PASS 아니면 → 실패 이유 피드백 → 재생성(최대 3회)
      ▼
   채택된 scenario.json  ─────────────┐
                                       ├─ [play] 참조 러너: 도입→탐색→심문→라운드단서→고발→판정
   플레이 시:                          ├─ [agent] 용의자 에이전트: 하드사실(타임라인·lies)+bio(돌발질문)+자기검증
   고발 채점:                          └─ [score_motive] 동기 자유서술 채점
```

## 파일

| 파일 | 역할 |
|---|---|
| `generate.py` | **바이블-먼저 2단계 생성** + 조건주입 + verify/난이도 게이트 + repair |
| `verify.py` | 규칙 검증기(R1~R5·MMO·흉기·보기·지도) |
| `difficulty.py` | 난이도 측정 + `difficulty_gate` (게이트) |
| `condition_sampler.py` | 데이터(코난·SHR·원작) 조건 주입 |
| `agent.py` | 용의자 에이전트: must_know/avoid + bio + **자기검증 루프** |
| `score_motive.py` | 동기 자유서술 채점(키워드+LLM) |
| `play.py` | 참조 플레이 러너(장소클릭→프로필 포함) |
| `test_consistency.py` | 자기오류 대량 테스트 |
| `SCHEMA.md` | 팀 인계 스키마 명세 |
| `scenario3.json` | **정답 예시**(검증+난이도+bio+profile 완비) = 생성 few-shot |
| `golden_sample.json` | 쉬운 베이스라인 예시(백설공주) |
| `out/*.json` | 검증+난이도 통과 시나리오 재고(흥부전·콩쥐팥쥐·장화홍련·별주부전) |

## 실행

```bash
pip install anthropic datasets huggingface_hub
export ANTHROPIC_API_KEY=sk-ant-...
export MM_DATA=~/Desktop/murdermystery/mm_kit/data   # 조건 샘플러용(선택)

python generate.py "흥부전" "조선"     # → out/bible.md + out/scenario.json (검증+난이도 통과분)
python verify.py out/scenario.json     # 단독 검증(API 불필요)
python difficulty.py out/scenario.json # 난이도 진단
python play.py out/scenario.json       # 터미널 플레이
python test_consistency.py C4 20       # 범인 자기오류 테스트
```

## 상태 (오늘 완성)

- ✅ 바이블-먼저 2단계 생성 (돌발질문 대응 bio + 프로필 카드 profile)
- ✅ 검증기(솔버빌리티) + 난이도 게이트(안 뻔함) 이중 통과 조건
- ✅ MMO(수단·동기·기회) 모델로 반전·유일해 구조 보장
- ✅ 에이전트 자기검증(ThinkThrice) + must_know/avoid + 누출 방지
- ✅ 동기 채점 · 참조 플레이 러너 · 자기오류 테스트
- ✅ 검증+난이도 통과 시나리오 4편 재고
