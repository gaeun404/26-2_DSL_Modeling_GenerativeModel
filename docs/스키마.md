# 시나리오 JSON 형식 (v2)

한 편 = 파일 하나. `_schema: 2`가 붙어 있으면 이 형식이다.
**JSON이 원본이고, 바이블(`*_novel.md`)은 여기서 자동 생성된다.**

---

## 최상위

| 키 | 무엇 |
|---|---|
| `meta` | `origin`(원작) · `era` · `title` |
| `background` | `setting_raw{era, location, culture}` · `atmosphere` |
| `adapted_story` | `tone` · `tone_shift`(반전) · `palette` |
| `trick` | `name` · `desc` (+ 오인 살인이면 `type:"misidentification"`, `conditions[]`) |
| `intro` | `original_summary` · `twist` · `narration[8+]` |
| `victim` | `name` · `role` · `bio` |
| `death` | `time_slot` · `place` · `weapon` · `weapon_class` · `method` · `scene_description` · `scene_inspection[]` |
| `time_slots` | `["초저녁","밤","새벽"]` |
| `map` | `max_move_per_slot` · `places[]` |
| `cast` | 용의자 **5명** (아래) |
| `clue_graph` | 단서 (아래) |
| `choices` `answer_format` `solution` | 정답과 보기 |
| `config` | `suspects:5` · `rounds:3|4` · `attempts` · `turns_per_round` |
| `relation_web` | 두 사람씩의 얽힘 (C(5,2)=10쌍) |
| `incidents` | 살인 + 별건(절도 등) |
| `timeline_events` | 분 단위 그날 밤 (12개+) |
| `place_layers` | 장소×라운드로 **다르게 보이는 것** |
| `events` | 중반 이벤트 |
| `scoring` `disclosure_rule` `phases` `ending` | 진행과 마무리 |
| `bgm` `voice` `visuals` `search` `detective` | 연출·UI |

## `map.places[]`

```json
{"id":"P2","name":"아내의 방","owner":"C1","pos":[2,1],
 "desc":"열쇠 꾸러미와 거울이 놓인 방","features":["금단의 방만 빠진 열쇠 꾸러미","창가의 촛대"]}
```

`owner`가 `null`이면 임자 없는 공용 자리(마당·우물가). 장소는 **6~8곳**.

## `place_layers`

```json
{"note":"라운드마다 다른 것이 보인다",
 "layers":{"P2":["1라운드에 보이는 것","2라운드에 보이는 것","3라운드에 보이는 것"]}}
```

라운드 수만큼, **서로 다른 글**이어야 한다. 같은 방을 다시 갈 이유가 여기서 생긴다.

## `clue_graph[]`

```json
{"id":"S1","channel":"location","medium":"탐색","location":"P2",
 "surface":"아내의 방에서 나온, 금단의 방 열쇠를 맞춰 보려 한 흔적.",
 "implies":"C1에게 감춘 사정이 있다",
 "weight":"secret","points_to":null,"exculpates":[],"affects":["C1","C4"],
 "reveal_round":3,"layer":3,"decisive":false,"incident":"I1"}
```

| 필드 | 뜻 |
|---|---|
| `channel` | `crime_scene`·`spine`(증언) = **처음부터 준다** / `location`·`record`·`physical` = **뒤져야 나온다** |
| `location` | 어느 장소에서 나오는가 |
| `reveal_round` | 몇 라운드부터 나오는가 |
| `points_to` | 이 사람을 가리킨다(함정일 수 있음) |
| `exculpates[]` | 이 사람을 배제한다 |
| `affects[]` | **교차 단서** — 이 단서가 건드리는 인물들 (3~8개 단서가 2명 이상을 건드림) |
| `decisive` | 결정타. 마지막 라운드에만. **짐 카드가 될 수 없다** |

## `cast[]` — 한 사람

```json
{"id":"C1","name":"새 아내","public":"영주가 새로 맞은 젊은 아내",
 "profile":{"age":"10대 후반","sex":"여","relation":"아내","status":"영주의 새 아내"},
 "kill_motive":"…","motive_label":"…","timeline":{"초저녁":"P2","밤":"P2","새벽":"P2"},
 "alibi_narration":"겉으로 하는 말","life_story":"200자+ 인생소설","bio":"…",
 "is_culprit":false,"mmo":{"means":false,"motive":true,"opportunity":false},
 "lies":[{"claim":"…","truth":"…","false_place":"P5"}]}
```

### 말투 — `persona.voice`

```json
{"form":"다정체","form_desc":"부드럽고 젊은 말",
 "endings":["-어요","-예요","-죠"],"ending_re":"(요|죠|예요|어요)$",
 "self":["저","제"],"address":"재판관님",
 "habit":"말끝을 자주 흐린다","ban":"'-하오' '-소' '-습니다' '-네' '-구려'로 끝내지 마라"}
```

**한 편에서 다섯 명의 `form`이 절대 겹치지 않는다.** 배경 계열마다 쓰는 말체가 다르다.

- 한국·동아시아 고전 — 하게체 · 하오체 · 합쇼체 · 해요체 · 소인체 · 올시다체 · 노라체
- 서양 고전 — 격식체 · 정중체 · 다정체 · 노숙체 · 공손체 · 탄식체
- 근현대 — 합니다체 · 해요체 · 반존대 · 건조체 · 노년체 · 설명체

내려 말하는 말체(하게체·노숙체·노년체·노라체)는 **신분이 높거나 40대 이상**만.

### 비밀 — `secrets[]`

```json
{"text":"금단의 방 열쇠를 몰래 맞춰 보려 했다","type":"호기심",
 "hidden_from":["C2"],"points_if_kept":1,
 "forced_by":["S1","B1"],
 "confession_line":"…사실이에요. 무서우면서도 궁금했어요. 허나 …",
 "note":"이것은 사정의 비밀이지 범행 자백이 아니다."}
```

`forced_by`가 **핵심**이다. 여기 적힌 단서·짐을 손에 쥐고 정곡을 찔러야 실토한다.
말로만 찌르면 흔들리기만 한다(FLINCH). 살인 자백은 여기 해당하지 않는다.

### 짐 — `belongings[]`

```json
{"id":"B1","name":"금단의 방 열쇠를 맞춰 보려 한 흔적","reveals":"…",
 "obtainable_by":["탐색:아내의 방","심문:금단"],"combines_with":"B4"}
```

`combines_with`는 **다른 사람 손에 있는 물증**과 짝이다. 두 개가 만나야 완성된다.

### 그 밖

`objectives[]`(이 자리에서 이루려는 것) · `pressure_points[]`(정곡 트리거) ·
`relationships{}`(상대별 서술, 반드시 "내가 모르는 것"으로 끝남) ·
`act_directions[]`(라운드별 목표·감출 것·내줄 것·연기 톤) ·
`appearance{}`(얼굴·체격·옷·표정 + 이미지 프롬프트) · `voice_spec{}`(음높이·속도·질감 + 음성 프롬프트)

## 진행

```json
"events":[{"round":2,"name":"사라진 물건","kind":"증거소실",
           "text":"…","effect":"판이 어떻게 바뀌는가"}]
"scoring":{"culprit_correct":5,"secret_revealed_each":1,"max":10}
"disclosure_rule":{"applies_to":"secrets_only",
  "triggers":[{"kind":"pressure_point"},{"kind":"evidence_shown"}]}
"ending":{"grades":[{"min":0,"name":"미궁","text":"…"}],
          "truth_reveal":"…","reconstruction":{"from":"timeline_events"}}
```

이벤트 `kind` 여섯: `새증언` `증거소실` `인물이탈` `외부개입` `자백번복` `두번째사건`
엔딩 등급은 **0점과 만점을 반드시 덮어야** 한다.

## `ui` — 화면 층 (v1)

게임 화면에 **실제로 뜨는 글자와 소리**. `ui.py`가 붙인다.
값 가운데 `cues.intro`, `place_cues.P2`, `event_cues.clue_found` 처럼 생긴 것은
같은 시나리오의 `bgm.*` 키를 가리키는 참조다.

| 키 | 무엇 |
|---|---|
| `ui.screens[]` | 화면 16종. 화면마다 `copy`(문구 전부) · `elements`(뜨는 것) · `bgm` · `sfx` |
| `ui.narration` | 오프닝 나레이션 **전문**. 컷마다 `text` · `illust.prompt_ko/en` · `render`(still/video) · `duration_sec` · `bgm` · `sfx`. `narrator`에 낭독 음성 사양 |
| `ui.reveal_sequence` | 엔딩 진상 **전문**. 다섯 박(정적→의심→결정타→이름→전부) |
| `ui.victim_card` | 피해자 카드. 신분·발견 장소·발견 시각·**사인(???로 가려 둠, `hidden_value`에 실제값)**·발견자 |
| `ui.suspect_cards[]` | 용의자 카드. 신분·나이·관계·`alibi_quote`(본인 말투 한 마디)·초상 지시(평정/흔들림/무너짐 3단)·목소리·전용 테마 |
| `ui.clue_cards[]` | 단서 카드. `name`(짧은 이름) · 종류 · 획득 장소 · **획득 방법** · `description` · 썸네일 지시 |
| `ui.place_screens[]` | 장소 조사 화면. 라운드마다 선택지 4개와 **결과 문장 3~4줄**, 어느 것이 단서를 물고 있는지(`finds`) |
| `ui.hud` | 상단 바 · 사건 개요 패널(피해자/장소/발견 시각/발견자) · 하단 내비 |
| `ui.notebook` | 사건수첩 3탭(인물·단서·메모) 문구 |
| `ui.toasts[]` | 알림 7종 (새 단서 · 결정타 · 라운드 · 이벤트 · 비밀 · 생명 · 혐의 벗음) |
| `ui.audio.music` | **화면 전용 곡 5개** — 타이틀·세계관 입력·로딩·수첩·지목. 지금까지 곡이 없어 아무거나 돌려 쓰던 자리 |
| `ui.audio.sfx` | **UI 효과음 20종** — 버튼·탭·수첩·장 넘김·혈흔 전환·알림 등. 사건용 `bgm.event_cues`와 겹치지 않는다 |

화면용 곡·효과음은 `bgm.music_scenes`에도 `ui:` / `uisfx:` 접두로 올라간다 —
음악 만드는 사람은 그 목록 하나만 보면 된다.

### 규칙

1. **사인은 검험 단서를 보기 전까지 `???`** — 카드에 답을 먼저 적지 않는다
2. **현장 검안은 뒤져서 나오지 않는다** — 시작할 때 준다(`reveal_round=1`)
3. **한 장소에서 같은 라운드에 단서가 둘 나오지 않는다** (`pace.py`가 맞춘다)
4. **결정타는 마지막 라운드에만** · **뼈대 단서는 라운드마다 하나 이상**
5. 조사 결과 문장은 헛탕 3줄 / 발견 4줄 — 마지막 줄만 붉게

### 나레이션 — 화면 제약 (UI 피드백 반영)

| 규칙 | 값 |
|---|---|
| 한 쪽에 들어가는 문장 | **2문장** |
| 한 쪽 글자 수 | **공백 포함 96자** — 넘으면 글자창에서 잘린다 |
| 한 문장 | 52자 이내 (넘으면 `ui.py`가 이어지는 말끝을 갈아 끼워 두 문장으로 쪼갠다) |
| 그림 | 쪽마다 한 장 · **1045×600** |

`ui.narration.pages[]` 에 쪽마다 `text` · `sentences` · `chars` · `over_limit` · `image{w,h,prompt}` 가 있다.
`over_limit_pages` 가 비어 있지 않으면 그 쪽은 손으로 줄여야 한다.
`generate.py` 프롬프트에도 같은 제약을 넣어 두었으니, 앞으로 뽑는 편은 처음부터 짧게 나온다.

### 사건 발생 — 쿠쿠쿵

원작 이야기가 사건으로 뒤집히는 쪽에 `is_incident: true` 와 `transition` 이 붙는다.

```
원작 BGM(cues.intro) 0.4초에 걸쳐 뚝 끊는다
무음 0.2초
쿠쿠쿵 (ui.audio.sfx.story_impact) — 저역 3연타 + 셋째 박에 현악 스탭
혈흔 전환 (ui.audio.sfx.blood_wipe)
머더미스터리 BGM(cues.discovery) 들어온다      · 전부 3.2초
```

그림도 이 쪽에서 색이 식는다(`cold desaturated palette`). 앞쪽 밝은 그림과 나란히 놓고 확인할 것.

### 범행 재연 — 엔딩 장면 (`ui.murder_reenactment`)

진상 5박 낭독이 끝난 직후, **범인이 실제로 죽이던 그 밤**을 컷 5장으로 재연한다.
게임 중에는 `visuals.scene_art.must_not_show`로 범인 얼굴이 금지지만, **여기서 처음 공개된다.**

| 컷 | 내용 | 얼굴 | 소리 |
|---|---|---|---|
| 1 그 밤 | 범인의 결심 + 동기 | **공개(클로즈업)** | 낮은 cues.reveal |
| 2 접근 | death.method의 접근 대목 | 실루엣(뒷모습) | 걸음마다 조이는 음악 |
| 3 범행 | 범행 그 순간 — 실루엣·그림자로만 | 실루엣 | **음악 뚝 → 범행음(ui.audio.sfx.murder_moment)만** |
| 4 위장 | death.method의 위장 대목 | 공개 | 무음 → 저역 드론 |
| 5 그리고 아침 | 현장 일러스트와 같은 구도의 새벽 | — | cues.ending으로 |

범행음은 흉기 갈래별로 다르다(자상=blade strike, 독=poison pour, 교살·타격·추락·화상·익사 각각).
그림은 1045×600 · 5장, `ui.art_specs`의 '재연 컷'에 잡혀 있다. 잔혹 묘사는 실루엣까지 — 소리로 암시한다.

### 그림 규격

| 종류 | 규격 | 어디에 |
|---|---|---|
| 스토리 삽화 | 1045×600 | 나레이션 쪽마다 |
| 주검 그림 (`victim_card.body_art`) | 1045×600 | 엎드려 쓰러진 자세, 얼굴 안 보이게 |
| 현장 전경 | 1045×600 | 현장 일러스트 |
| 장소 배경 (`place_screens[].art`) | 1045×600 | 장소 조사 화면 |
| 지도 썸네일 (`place_screens[].map_thumb`) | 320×200 | 지도 |
| 인물 초상 | 512×768 | 카드·수첩·심문 (표정 3단) |
| 인물 전신 | 600×1200 | 장소 조사 화면 왼쪽 |
| 단서 썸네일 | 256×256 | 수첩 단서 탭 |
| 사건 표지 (`catalog.cases[].cover`) | 640×400 | 준비된 사건 목록 |

편마다 몇 장이 필요한지는 `ui.art_specs` 에 표로 들어 있다.

### 이미 만들어 둔 사건 꺼내 쓰기

커스텀 생성 모델은 아직 만드는 중이라, 지금은 **입력이 우리 목록에 걸리면 그 편을 그대로 연다.**

```
python3 catalog.py                 out/catalog.json 을 만든다 (23편)
python3 catalog.py --find 라쇼몽    걸리는 편이 있는지 확인
```

`screens[world_input].branch` 에 규칙이 있다 — aliases 정확일치 → 부분일치.
걸리면 로딩 화면이 `mode=load`(“사건 기록을 여는 중…”, 상태 줄 2개)로 바뀌고 2~3초 만에 나레이션으로 넘어간다.

## 손대면 안 되는 규칙

1. **증거 없이는 실토도 자백도 없다** — `forced_by` 없는 비밀은 만들지 않는다
2. **결정타는 짐 카드가 될 수 없다** — 쥐는 순간 게임이 끝난다
3. **한 편에서 말체는 겹치지 않는다**
4. **프롬프트에 따라 쓸 대사 예문을 넣지 않는다** — 모델이 그대로 베낀다
5. **길이를 지시하지 않는다** — 담을 내용을 지시한다
