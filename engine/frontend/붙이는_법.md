# 피그마에서 뽑은 화면에 엔진 붙이기

프론트는 이미 Vercel에 올라가 있고(`murder-mystery-ui.vercel.app`), 붙일 것은 백엔드다.
순서는 셋뿐이다 — **서버를 올린다 → 주소를 알려 준다 → 화면에서 함수를 부른다.**

---

## 0. 먼저 알아야 할 함정 하나

**https 화면에서 http 서버는 못 부른다.** 브라우저가 막는다(mixed content).
Vercel은 https이므로 `http://127.0.0.1:8000`을 부르면 아무 일도 안 일어나고
콘솔에만 조용히 에러가 뜬다. 그래서 백엔드도 https로 올려야 한다.

급하면 터널이 제일 빠르다 — 서버는 내 노트북에 두고 주소만 https로 빌린다.

```bash
# 터미널 1
python3 server.py --port 8000
# 터미널 2  (설치: brew install cloudflared)
cloudflared tunnel --url http://localhost:8000
#   → https://xxxx-yyyy.trycloudflare.com  주소가 찍힌다. 이게 API 주소다.
```

시연 당일에 노트북을 켜 둘 수 없다면 3번(배포)으로 간다.

## 1. 화면에서 부르기

`frontend/mmapi.js` 를 프로젝트에 복사한다. 의존성도 빌드 설정도 없다.

```js
import { mm, stanceLabel, faceOf } from "./mmapi.js";

mm.base = import.meta.env.VITE_API_BASE || "https://내-서버-주소";

// 판 열기 — 인트로 구간 자료가 한 번에 온다
const g = await mm.start("91_dsl_demo.json");
g.case.logline        // S-05 한 줄
g.opening             // S-06 오프닝 14쪽 [{page,text,image}]
g.crime_scene.clues   // S-08 시작 단서 5장
g.victim              // S-09 피해자 카드
g.suspects            // S-10 용의자 소개 5장 (photo 경로 포함)

// 라운드 화면 — 상태는 mm.state 에 늘 최신으로 들어 있다
mm.onState = (st) => setState(st);     // React면 이 한 줄
mm.state.turns_left                     // 남은 행동
mm.state.cast                           // 인물 카드 (met, alibi, secrets_open, pressure)
mm.state.notebook                       // 수첩 (단서만)
mm.state.confront.unlocked              // 대질 잠금

// 지도 → 조사
const { places } = await mm.map();
const r = await mm.search("PC");
r.empty ? "여긴 오늘 밤 달라진 게 없다" : r.found   // 빈 방은 턴을 안 쓴다

// 심문
await mm.meet("C1");                                  // 첫 대면 알리바이, 0턴
const t = await mm.ask("C1", "그 시각 어디 계셨습니까.", "K1");
t.line          // 대사 (서버에 키가 없으면 null)
t.stance        // ANSWER/DEFLECT/FLINCH/ADMIT/BREAK
faceOf(t.stance)          // 초상 표정 3단: calm / shaken / broken
t.secrets_opened          // 열린 비밀 문장 배열

// 대질 · 라운드 · 지목
await mm.confront("C1", "C5", "그 시각 어디 계셨는지 다시 말씀해 주세요.");
await mm.nextRound();
const end = await mm.accuse("C5");   // 여기서 처음 진상이 열린다
```

에러는 **그대로 띄워도 되는 한국어 한 줄**로 던진다.

```js
try { await mm.search(pid); }
catch (e) { toast(e.message); }   // "이 라운드에 남은 행동이 없습니다."
```

## 2. 화면 ↔ 부르는 것

| 화면 | 부르는 것 |
|---|---|
| S-05~S-10 도입 전부 | `mm.start()` 한 번 |
| S-11 라운드 프레임 | `mm.state` (따로 부를 필요 없음) |
| S-13 지도 | `mm.map()` |
| S-14 장소 조사 | `mm.search(placeId)` |
| P-06 첫 대면 | `mm.meet(castId)` |
| S-15 심문 | `mm.ask(castId, 질문, 단서id?)` |
| S-16 대질 | `mm.confront(a, b, 질문)` |
| S-12·S-20 라운드 | `mm.nextRound()` |
| S-18 수첩 | `mm.state.notebook` |
| S-21~S-24 지목·진상·재연·엔딩 | `mm.accuse(castId)` |

자세한 응답 JSON은 `docs/API명세.md`, 눌러 보려면 서버의 `/docs`.

## 3. 백엔드 올리기

어디든 파이썬이 돌면 된다. 무료로 빠른 것은 **Render**.

1. 이 저장소를 GitHub에 올린다(비공개로).
   ⚠️ `assets/dsl/` 실물 사진과 `91_dsl_demo.json`은 여섯 분 동의 전에는 공개 저장소에 두지 않는다.
2. Render → New → Web Service → 그 저장소 선택
3. 설정은 이것뿐:
   - Build: `pip install -r requirements.txt`
   - Start: `python3 server.py --host 0.0.0.0 --port $PORT`
4. Environment 에 넣을 것:
   - `MM_API_KEY` — 용의자 대사를 서버가 만든다. **키는 브라우저로 안 나간다.**
   - `ALLOW_ORIGINS` — `https://murder-mystery-ui.vercel.app` (안 주면 전부 열린다)
5. 올라오면 `https://…onrender.com/health` 가 `{"ok":true}` 를 뱉는다. 그게 API 주소다.

Vercel 쪽에는 환경변수 하나만 — `VITE_API_BASE`(또는 `NEXT_PUBLIC_API_BASE`)에 그 주소.

> 무료 플랜은 한동안 안 부르면 잠든다. 첫 요청이 30초쯤 걸릴 수 있으니,
> 시연 직전에 `/health`를 한 번 눌러 깨워 두면 된다.

## 4. 붙었는지 확인하는 순서

```js
await mm.health()      // {ok:true, llm:true} — llm:false 면 서버에 키가 없다는 뜻
await mm.scenarios()   // 사건 50편이 오면 배선은 끝난 것
```

그다음 서버의 `/demo` 를 열어 본다. 그 화면이 도는데 내 화면이 안 돌면
**프론트 문제**, 그것도 안 돌면 **서버 문제**다. 어느 쪽인지부터 가른다.
